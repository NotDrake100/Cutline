## Six rules

1. Black editorial canvas with precise grid lines.
2. Condensed all-caps display + restrained mono metadata.
3. Lime only for actions, indexes, key signals.
4. Square media panels; imagery supplies variation.
5. Numbered section labels + generous negative space.
6. Direct typographic CTAs — ban purple gradients, glow buttons, AI-slop polish.
