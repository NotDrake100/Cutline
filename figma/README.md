# Cutline — Figma kit

Open **`Cutline Design Kit.html`** in a browser, then import into Figma with [html.to.design](https://www.figma.com/community/plugin/1159123024924461421/html-to-design) (free community plugin):

1. Open Figma → create a blank file named **Cutline**
2. Plugins → html.to.design → Import from URL or paste HTML
3. Or: select the frames on the HTML page → copy → plugin paste

Tokens live in `tokens.json` (cream + Ace lime). Logo mark: `../apps/web/assets/cutline-mark.png`.

## Product (do not drift)
- Cutline is your AI desk. News in, post out. Raw video in, edited cut out. You approve.
- News search → finished post; video upload → fully edited cut
- Not a newspaper CMS. Not “pack” / “template” as the headline idea.
